# Ecommerce Platform

Bootstrap monorepo. Backend applications in `services/`: `ecommerce`, `identity`, `notification`, `media`; BFFs reserved. Frontends in `web/`: Backoffice skeleton and Storefront placeholder.

Java 25 / Spring Boot 4.1.1; React 19 / TypeScript / Vite. No business code migrated. Reference repositories: [BE](https://github.com/XdpsX/ecommerce-be), [Backoffice](https://github.com/XdpsX/ecommerce-backoffice), [Identity](https://github.com/XdpsX/practical-identity), [Notification](https://github.com/XdpsX/notification-service).

See `docs/06-development/bootstrap.md`.
