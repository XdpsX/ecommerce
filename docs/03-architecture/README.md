# Architecture — bootstrap scope

**Current reality:** two Java skeletons and a placeholder storefront; no domain implementation has been migrated.

**Target direction (not yet implemented):** Ecommerce modular monolith, separate Identity/Notification/Media capabilities, React Backoffice and Storefront, and optional BFFs. The exact service topology, auth flows, contracts and deployment are to be verified and documented through future ADRs.

Source references: [ecommerce-be](https://github.com/XdpsX/ecommerce-be), [ecommerce-backoffice](https://github.com/XdpsX/ecommerce-backoffice), [practical-identity](https://github.com/XdpsX/practical-identity), [notification-service](https://github.com/XdpsX/notification-service).
